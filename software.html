JUG

JAX-based Unified pulsar timinG. A fully independent pulsar timing package — clock corrections, timing models, noise and deterministic signals, fitting — that runs on CPU or GPU, has a Python API and an interactive GUI, and handles millions of TOAs. More than 50× faster than PINT and agrees with it at the picosecond level.

GitHub · Paper

ATLAS

Bayesian inference for pulsar timing arrays in JAX and NumPyro. Samples timing-model, white-noise, red-noise, deterministic-signal and gravitational-wave-background parameters jointly in one model with gradient-based samplers (NUTS, HMC-within-Gibbs), using JUG for the non-linear timing model.
