Software

JUG

JAX-based Unified pulsar timinG. A fully independent pulsar timing package — clock corrections, timing models, noise and deterministic signals, fitting — that runs on CPU or GPU, has a Python API and an interactive GUI, and handles millions of TOAs. More than 50× faster than PINT and agrees with it at the picosecond level.

GitHub · Paper

ATLAS

Bayesian inference for pulsar timing arrays in JAX and NumPyro. Samples timing-model, white-noise, red-noise, deterministic-signal and gravitational-wave-background parameters jointly in one model with gradient-based samplers (NUTS, HMC-within-Gibbs), using JUG for the non-linear timing model.

GitHub

Data

MeerKAT Pulsar Timing Array

Sub-banded arrival times, timing models, noise models and calibrated pulsar archives from the MPTA data releases.

  • First data release · paper
  • 4.5-yr data release · paper
  • 6.5-yr data release (in prep.)

Parkes Pulsar Timing Array

Calibrated profiles, flux-density dynamic spectra, wide-band templates, arrival times and timing models for 32 millisecond pulsars observed with Murriyang, the Parkes radio telescope, over up to 18 years.

  • Third data release: part 1 · part 2 · paper

International Pulsar Timing Array

The combined data set of the regional pulsar timing arrays, including NANOGrav, the EPTA, the PPTA, the InPTA and the MPTA.

  • Third data release (in prep.)
